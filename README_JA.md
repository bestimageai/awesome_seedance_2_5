```text
23–30秒：給水塔の下の差し込み口に円筒を収める。青い波が橋で止まり、琥珀色の光が塔に沿って上がる。街の輪郭を広く見せて終える。

風、足音、金属の振動、強まる電気のうなりを使う。カットをまたいでも、屋上の位置関係、円筒の形、進行方向を保つ。
```

</details>

<a id="what-makes-these-prompts-usable"></a>

## 使いやすいプロンプトの条件

[Seedance 2.5公式ページ](https://seed.bytedance.com/en/seedance2_5)では、より長尺の映像・音声生成、参照素材による制御、編集機能を紹介しています。モデル提供元の機能と個々のサービスで利用できる操作は異なります。すべての編集・延長操作に対応するbestimage.aiのエンドポイントがあるとは限りません。

役立つ演出案は、求める動作の一つひとつを目で確認できる形にします。

```text
[モード] テキストから動画 / 画像から動画 / 参照素材から動画 / 対応する編集操作
[目的] 視聴者、用途、目標の長さ、構図
[参照素材] 提供する画像・動画・音声それぞれに明確な役割を1つ指定
[固定要素] 同一性、形状、物の数、配置、光の向き
[時間軸] 導入 → 動作 → 結果 → 最終フレーム
[カメラ] 開始位置、経路、速度、焦点、停止点
[音] セリフ、環境音、フォーリー、音楽、同期の目印
[確認] 変えてはいけない要素と、不採用となる出力の条件
```

時間軸は創作意図を表すもので、フレーム単位の正確な実行を保証しません。公開前に結果と照らし合わせて確認してください。

<a id="a-practical-creation-sequence"></a>

## 実践的な制作の手順

1. シナリオを選び、必要なモードを利用中のサービスが提供しているか確認します。
2. 使用許可のある素材を用意し、アップロード順を保ちます。参照素材で制御したいものが人物の同一性、動き、環境、音のどれなのかを明記します。
3. 目標の時間軸を選択した動画の長さに合わせます。画像から動画を生成する場合は、未対応のアスペクト比パラメーターを作らず、意図した構図の入力画像を準備します。
4. まず限定的な動作を試し、その後にカメラの動きと音を加えます。1回の試行で変える要素は1つにします。
5. 各フレームの形状、身体構造、文字の読みやすさ、物の数、物理的接触、編集領域の境界を確認します。音声と延長部分のつなぎ目は個別に確認します。
6. 正確なタイトル、訴求文、クレジット、各言語の画面文言を生成で安定して保てない場合は、後編集で追加します。
