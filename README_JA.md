# Seedance 2.5 プロンプト集：画像から動画を作る実践ガイド

[English](README.md) · [简体中文](README_ZH.md) · [日本語](README_JA.md) · [Español](README_ES.md) · [15言語のプロンプト](prompts/i18n/README.md)

![Seedance 2.5の企画を表すコンセプト画像。Seedanceの生成結果ではありません](assets/seedance-2-5-cover.png)

**bestimage.aiチーム**が整理・保守する、**重複を除いた120シーン**のSeedance 2.5プロンプト集です。既存の100シーンを書き直し、20シーンを追加しました。構成は中国語の基本カタログ60シーン、英語の基本カタログ40シーン、中国語・英語の両方で提供する新規20シーンです。新規20シーンは言語ごとに重複して数えません。

15言語の対応範囲は、各言語で共通の6シーンを紹介するサンプル集です。日本語で読めるのもこの6シーンであり、120シーン全体の日本語訳ではありません。掲載画像はコンセプト画像であり、Seedanceで生成した動画やその実測結果を示すものではありません。

実際にテストしたプロンプトを共有する際は、設定、入力素材、実際の出力を添え、[貢献ガイド](CONTRIBUTING.md)を参照してください。採用された内容は確認・編集後に投稿者名とともに収録される場合があります。

> **bestimage.aiでの制作フロー（以下の入口は英語です）：** テキストだけで始める場合は[Seedance 2.5 Text-to-Video](https://bestimage.ai/models/bytedance/seedance-2-5-text-to-video/)、開始フレームを1枚使う場合は[Image-to-Video](https://bestimage.ai/models/bytedance/seedance-2-5-image-to-video/)、複数素材を参照する場合は[Reference-to-Video](https://bestimage.ai/models/bytedance/seedance-2-5-reference-to-video/)を選びます。Reference-to-Videoには少なくとも1本の参照動画が必要です。
>
> 絵コンテや開始フレームを先に作る場合は、別の画像生成ワークフローである[GPT Image 2 API](https://bestimage.ai/models/openai/gpt-image-2/)を利用できます。GPT Image 2は動画インターフェースではありません。[bestimage.ai連携ガイド](docs/bestimage-ai-api-guide.md)で手順を確認してください。設定、料金、入力条件、API仕様は変わる場合があるため、利用時に各モデルページで確認してください。

## Seedance 2.5 向けの基本構造

各プロンプトは制作意図を整理するための演出案です。記載した尺や動作がそのまま利用中のAPIで実現できる保証はありません。現在の入力条件や対応範囲を確認し、実際の出力を評価してください。形容詞を並べるだけでなく、素材の役割、固定要素、時間配分を分けて書きます。

```text
[モード] テキストから動画 / 画像から動画 / 参照素材から動画
[目的] 用途、対象、感情、尺、アスペクト比
[素材の役割] Image 1は人物のみ、Video 1はカメラ経路のみ参照
[固定要素] 顔、衣装、製品形状、背景、光源、物の数
[時間軸] 導入 → 主動作 → 変化 → 最終画面
[撮影] 画角、カメラ高、移動経路、速度、焦点、停止位置
[演技と物理] 視線、手、重さ、慣性、接触、布、水、煙
[音] セリフ、環境音、効果音、音楽、同期点
[禁止] 変形、重複、手足の追加、偽文字、ロゴ、透かし
```

## コピーできる例：陶器のコーヒードリッパー

これは[日本語プロンプト集のI18N-01](prompts/i18n/prompt-library.ja.md)の要約です。完全な入力指定と時間軸は同ファイルにあります。

```text
Image 1を開始フレームとして使用する。外側に6本のリブがあるコバルトブルーの陶器製ドリッパー、乾いたコーヒー粉が入った白いペーパーフィルター、透明なサーバーを固定する。左側からの朝の光と製品の形を維持し、ブランド表示は入れない。

20秒、16:9。最初の4秒で乾いた粉を見せ、細口ケトルの注ぎ口が右上から入る。4〜11秒は細い連続した水流でフィルターの内側に小さな円を描く。11〜16秒で注湯を止めて注ぎ口を戻し、少し引いてサーバーの液量が徐々に増える様子を見せる。16〜20秒は製品を斜め前から見せ、右側に後から文言を配置する余白を残す。

音は注湯、滴下、静かな室内環境音のみ。液量の連続性と物体の接触を保つ。余分な容器、浮遊するコーヒー、文字、ロゴ、大きな湯気、透かしは禁止。
```

## 画像から動画を作るときの確認事項

- 顔、衣装、製品の形、物の数、構図、主光源を固定する。
- 被写体、環境、カメラの動きを別々に書く。
- 各参照素材には明確な役割を与える。参照素材からの動画生成には、少なくとも1本の動画を用意する。
- カメラの開始位置、経路、速度、停止点を明記する。
- 終盤に動きが落ち着く時間と、最終構図を確認する時間を設ける。
- 画面の文字は承認済みの画像で用意し、動画モデルに翻訳を任せない。
- 実際の出力で形状、文字、音声、物理挙動を確認する。商用利用では、画像・音声・人物・ブランドの権利も確認する。

コンセプト画像や未検証の演出案を、モデルの性能実証、物件の事実証明、製品の安全認証として扱わないでください。
