## Choose by available input

| What you have | Workflow | Input boundary |
| --- | --- | --- |
| Written idea only | Text-to-video | Define subject, timing, camera, sound and final frame |
| One first image, optional matching last image | Image-to-video | Lock geometry and composition; do not invent additional media fields |
| One or more videos, optional images/audio | Reference-to-video | At least one video is required on bestimage.ai; assign each asset one explicit job |
| Images without a video | Prepare an image-to-video first frame, or obtain an authorized video for reference generation | Do not pretend an image board satisfies a required video input |
| An existing clip to edit or extend | A service exposing that exact operation | Check operation support and review preserved frames, regions and joins |
| No static reference yet | Separate GPT Image 2 image workflow | Review the image before choosing a Seedance video mode |

## First-pass acceptance test

1. Identity, wardrobe, product shape, labels, and object count remain stable.
2. Doors, walls, furniture, foreground occlusion, and travel direction remain coherent.
3. Actions have plausible weight, contact, inertia, and recovery.
4. The camera follows one understandable path and reaches a deliberate stop.
5. Dialogue, ambience, Foley, and music are separated and synchronized.
6. Only approved, legible text appears; no invented claims, logos, or prices.
7. Likeness, asset, music, trademark, safety, and advertising rights are reviewed.
8. Edits and extensions preserve the intended source boundaries; a whole new clip is not evidence of a successful local operation.
