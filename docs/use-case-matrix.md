## 按已有输入选择

| 已有内容 | 工作流 | 输入边界 |
| --- | --- | --- |
| 仅文字构想 | 文生视频 | 完整定义主体、时序、镜头、声音与尾帧 |
| 一张首帧与可选匹配尾帧 | 图生视频 | 锁定几何和构图，不编造额外素材字段 |
| 一段以上视频及可选图片、音频 | 参考生视频 | bestimage.ai至少需要一段视频，每份素材只承担明确职责 |
| 只有图片没有视频 | 准备图生视频首帧，或先获得授权视频再用参考生成 | 不把图片参考板当成已满足必需视频输入 |
| 需要修改或延长已有片段 | 支持该项操作的服务入口 | 核实功能并检查保留区域、时间边界与连接处 |
| 尚无静态参考 | 独立的GPT Image 2图像工作流 | 先审核图像，再选择Seedance视频模式 |

## 首轮验收

1. 身份、服装、产品形状、标签和物体数量保持稳定。
2. 门窗、墙面、家具、遮挡和运动方向保持连贯。
3. 动作有合理的重量、接触、惯性与恢复过程。
4. 镜头遵循一条可理解的路径，并到达明确终点。
5. 对白、环境声、拟音和音乐分层且同步。
6. 仅出现批准且清楚的文字，不编造声明、标志或价格。
7. 核对肖像、素材、音乐、商标、安全及广告相关权利。
8. 编辑与延长保留指定源片边界，新生成整片不等于局部操作已成功。

模型页面入口、API地址和接入说明见[API工作流指南](bestimage-ai-api-guide.md)。
