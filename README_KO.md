### X01 · 작은 주방과 배고픈 승객

표정이 풍부한 캐릭터와 가까이서 들리는 음식 소리로 유쾌한 결말을 만듭니다.

```text
7–15초: 떨어지는 밀가루, 볼을 두드리는 나무 숟가락, 팬에서 녹는 버터를 번갈아 보여 준다. 각 소리를 눈에 보이는 접촉에 맞춘다.
15–24초: 요리사가 접시에 팬케이크를 놓는다. 참새가 접시를 당기려 하자 요리사가 손가락 하나로 붙잡는다.
24–30초: 요리사가 작은 조각을 떼어 나누어 준다. 배가 갈대 옆을 지나가는 동안 둘이 먹는 모습을 계속 보여 준다.

따뜻한 아침 햇살, 촉감이 느껴지는 펠트와 나무, 잔잔한 물소리, 부드러운 코믹 타이밍을 사용한다. 대사와 화면 글자는 넣지 않는다.
```

### X02 · 재킷 하나, 네 가지 분위기

스타일링이 바뀌어도 주인공 의상을 알아볼 수 있도록 특징을 유지합니다.

```text
녹슨 철빛의 데님 재킷 한 벌을 중심으로 24초 패션 영상을 만든다. 제공된 의상 이미지를 사용해 솔기, 단추, 주머니, 원단 색상을 유지한다. 처음부터 끝까지 같은 성인 모델과 햇살이 드는 스튜디오를 사용한다.

0–4초: 모델이 재킷 단추 하나를 잠그는 모습을 클로즈업한 뒤 위로 틸트하여 편안한 미소를 보여 준다.
4–9초: 흰 셔츠와 어두운 바지를 입은 캐주얼 차림을 보여 준다. 모델이 창 쪽으로 몸을 돌린다.
9–14초: 돌아가는 어깨의 움직임을 연결해 검은 원피스 위에 재킷을 걸친 두 번째 차림으로 전환한다.
14–19초: 소매가 렌즈 앞을 지나가면 줄무늬 상의와 크림색 바지를 입은 세 번째 차림이 드러난다.
19–24초: 마지막 의상에 재킷을 걸친 모습을 보여 주고 전신 포즈로 마무리한다.

부드러운 신발 소리와 절제된 비트를 사용한다. 모든 컷에서 재킷의 구조를 그대로 유지한다. 자막이나 추가 로고를 넣지 않는다.
```

</details>

### X08 · 압화와 종이, 조용한 소리

가까운 구도와 질감이 느껴지는 소리로 공예의 각 단계를 보여 줍니다.

```text
성인의 손이 참나무 책상에서 압화 책갈피를 만드는 24초 탑 뷰 공예 영상을 만든다. 크림색 종이 띠 하나, 말린 제비꽃 세 송이, 작은 붓 하나, 연보라색 리본 한 줄을 사용한다.

0–6초: 종이를 중앙에 세로로 놓고 옆에 꽃 세 송이를 배치한다. 종이와 꽃잎의 부드러운 소리를 담는다.
6–12초: 붓으로 투명 접착제를 얇게 바른 뒤 꽃을 한 송이씩 줄기 부분으로 들어 종이 위에 놓는다.
12–18초: 깨끗한 보호 시트를 덮고 꽃을 부드럽게 누른다. 접촉을 보여 주고 꽃의 배치를 유지한다.
18–24초: 완성된 책갈피로 전환한다. 뚫린 구멍에 리본을 끼우고 창 쪽으로 들어 올린 뒤 마지막 구도를 유지한다.

부드럽게 퍼지는 오후 빛과 붓질, 종이, 리본에서 가까이 들리는 조용한 소리를 사용한다. 책상 배치를 안정적으로 유지하고 자연스러운 손동작을 보여 준다. 내레이션이나 글자 라벨은 넣지 않는다.
```

</details>

```text
부드러운 자연광, 자연스러운 피부 질감, 유리창에 부딪히는 빗소리, 조용한 가르릉 소리를 사용한다. 내내 고양이의 몸을 받쳐 준다. 끊김 없는 한 번의 촬영, 인물 한 명, 고양이 한 마리로 구성하고 줌이나 배경 음악은 사용하지 않는다.
```

</details>


```text
성인 친구 두 명이 밤에 간식을 사러 가는 30초 브이로그를 만든다. 이미지 1은 스마트폰을 든 친구의 외모를, 이미지 2는 간식을 고르는 친구의 외모를 정한다. 두 사람의 동일성과 의상을 유지한다.

0–7초: 스마트폰 후면 카메라로 간식을 고를 친구가 작은 편의점 입구를 통과하는 모습을 따라가며 시작한다.

23–30초: 지나가는 자동차의 전조등이 배경을 가로지르는 동안 두 사람이 차양 아래에서 함께 웃는다.

실내 형광등, 실외의 따뜻한 가로등, 냉장고 작동음, 발소리, 또렷한 대화 음성을 사용한다. 각 숏 안에서 스마트폰 촬영 담당을 바꾸지 않고 간식 봉지는 구입한 친구의 손에 유지한다.
```

| Seedance 2.5: 아이디어 또는 글로 작성한 숏 목록 | [텍스트 기반 영상 생성 API](https://bestimage.ai/models/bytedance/seedance-2-5-text-to-video/) | 피사체, 시간대별 동작, 카메라, 사운드를 담은 연출 기획안 |
| Seedance 2.5: 첫 프레임에 움직임 추가 | [이미지 기반 영상 생성 API](https://bestimage.ai/models/bytedance/seedance-2-5-image-to-video/) | 필수 시작 이미지와 선택 사항인 대응 종료 이미지 |
| Seedance 2.5: 참조 자료를 활용한 제작 | [참조 자료 기반 영상 생성 API](https://bestimage.ai/models/bytedance/seedance-2-5-reference-to-video/) | 필수 참조 영상 최소 1개와 선택 사항인 이미지·오디오 |
| GPT Image 2: 이후 영상 제작에 사용할 정지 이미지 준비 | [GPT Image 2 API](https://bestimage.ai/models/openai/gpt-image-2/) | 콘셉트 프레임, 캐릭터 시트, 스토리보드용 별도 이미지 프롬프트 |

**GPT Image 2는 이미지 제작 워크플로이며 Seedance 영상 엔드포인트가 아닙니다.** 생성한 참조 이미지도 영상 요청에 사용하기 전에 시각적 품질과 권리를 검토해야 합니다. 이미지로만 구성된 참조 보드는 bestimage.ai의 참조 자료 기반 영상 생성에 필요한 필수 영상 입력을 충족하지 않습니다.

입력 자료의 역할, API 연동, 생성·편집·연장의 차이는 [bestimage.ai 모델 및 API 워크플로 가이드](docs/bestimage-ai-api-guide.md)를 참고하세요. bestimage.ai의 API 기본 URL은 `https://api.flaq.ai`입니다. bestimage.ai 계정에서 발급한 API 키를 사용하세요.

<a id="what-makes-these-prompts-usable"></a>

## 활용하기 좋은 프롬프트의 조건

[Seedance 2.5 공식 페이지](https://seed.bytedance.com/en/seedance2_5)는 더 긴 영상·오디오 생성, 참조 제어, 편집 기능을 설명합니다. 모델 제공업체의 기능과 개별 서비스에서 제공하는 제어 항목은 다릅니다. 모든 편집 또는 연장 작업에 대응하는 bestimage.ai 엔드포인트가 있다고 가정하지 마세요.

유용한 기획안은 요청한 동작 하나하나를 눈으로 확인할 수 있게 만듭니다.

```text
[모드] 텍스트 기반 영상 생성 / 이미지 기반 영상 생성 / 참조 자료 기반 영상 생성 / 지원되는 편집 작업
[목표] 시청자, 목적, 목표 길이, 구도
[참조 자료] 제공한 이미지·영상·오디오 자료마다 명확한 역할 하나 지정
[고정 요소] 동일성, 형태, 물체 수, 배치, 빛의 방향
[타임라인] 도입 → 행동 → 결과 → 마지막 프레임
[카메라] 시작 위치, 경로, 속도, 초점, 정지 지점
[사운드] 대사, 환경음, 폴리, 음악, 동기화 신호
[검토] 바뀌면 안 되는 요소와 결과물을 수용할 수 없는 조건
```

타임라인은 창작 의도를 표현하며 프레임 단위의 정확한 실행을 보장하지 않습니다. 게시하기 전에 결과물이 의도에 맞는지 확인하세요.

<a id="a-practical-creation-sequence"></a>

## 실용적인 제작 순서

1. 시나리오를 선택하고 이용 중인 서비스가 필요한 모드를 제공하는지 확인하세요.
2. 사용 권한이 있는 자료를 제공하고 업로드 순서를 유지하세요. 참조 자료가 인물의 동일성, 움직임, 환경, 사운드 중 무엇을 제어할지 명시하세요.
3. 목표 타임라인을 선택한 영상 길이에 맞추세요. 이미지 기반 영상 생성에서는 지원하지 않는 화면비 매개변수를 만들지 말고 의도한 구도의 입력 이미지를 준비하세요.
4. 먼저 제한된 동작을 시험한 뒤 카메라 움직임과 사운드를 추가하세요. 반복할 때마다 변수 하나만 바꾸세요.
5. 모든 프레임의 형태, 신체 구조, 글자 가독성, 물체 수, 물리적 접촉, 편집 영역 경계를 확인하세요. 오디오와 연장 부분의 연결은 별도로 확인하세요.
6. 정확한 제목, 홍보 문구, 크레딧, 현지화된 인터페이스 문구를 생성 과정에서 안정적으로 유지할 수 없다면 후반 작업에서 추가하세요.
