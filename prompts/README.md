# Seedance 2.5：120 个场景总索引

[English](../README.md) · [简体中文](../README_ZH.md) · [15 语种样例](i18n/README.md) · [模式与 API 指南](../docs/bestimage-ai-api-guide.md)

由 bestimage.ai 团队整理、改写与维护。以下按唯一场景 ID 计数：24 + 36 + 12 + 28 + 20 = **120**。翻译、不同颜色版本、分章节生成和参考板分格不重复计数。所有条目均为未经视频生成实测的创作简报，不能把概念图当作模型效果证据。

前60条以简体中文为核心，61–100为英文核心，101–120有完整中英版本。14份语言样例文件各含6个共享场景，不代表每种语言都有120条完整译文。参考视频和音频需自行提供；编辑、延长要先核实实际入口支持。

## 标准提示词字段

使用目的、输入角色、主体不变量、明确时间轴、镜头起点与终点、动作接触与惯性、声音层次、重要限制、最终画面及验证记录。对不适用的字段不机械堆砌；模板与逐项检查见[提示词指南](../docs/prompting-guide.md)。

## 按输入选择

- 仅有文字：选择文生视频，完整描述场景和动作。
- 一张首帧与可选尾帧：选择图生视频，保持几何和构图一致。
- 需要多个参考角色：bestimage.ai参考生视频还要求至少一段视频，不能只上传图片或音频。
- 修改或延长已有视频：先核实入口提供对应操作，不把新视频生成称为已验证编辑。
